À propos de ce projet

Catalogue de pièces automobiles réalisé pour m'entraîner à construire une interface complète, sans framework.

  • Code structuréModules séparés pour les données, les avis, les favoris et le contact. La logique des filtres est testée.
  • SécuritéLes avis sont affichés avec textContent pour éviter l'injection de code (faille XSS).
  • AccessibilitéChamps avec labels, focus visible, navigation au clavier et mode sombre automatique.
  • ResponsiveL'interface s'adapte du téléphone à l'ordinateur.
  • HTML5
  • CSS3
  • JavaScript (modules ES)
  • localStorage
  • Netlify Forms
  • Tests Node.js
